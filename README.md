# Password Security Auditor

A Python-based password security auditing tool that analyzes password strength and provides security-related feedback.

## Features

- Password length analysis
- Uppercase, lowercase, digit, and special-character detection
- Character-type analysis
- Password strength scoring
- Common-password detection
- Repeated-character detection
- Sequential-pattern detection
- Character-pool calculation
- Theoretical entropy estimation
- Entropy classification
- Security recommendations
- Secure password generation using Python's `secrets` module
- Selectable character types for generated passwords
- Password length validation
- Generated-password analysis
- Interactive menu

## Requirements

- Python 3
- No external Python packages are currently required

## Usage

Run the program with:

```bash
python password_security_auditor.py
```

Follow the interactive prompts to analyze passwords or generate secure passwords.

## Security Note

This tool is intended for educational and personal security-auditing purposes.

Password strength scores and entropy estimates are theoretical indicators and should not be treated as guarantees of password security.

Passwords should not be stored or shared unnecessarily.

## Current Status

Completed educational milestone with password analysis, security recommendations, entropy estimation, and secure password generation.
